# Лабораторна робота №5. Форми та обробка даних у Flask

Форма реєстрації на навчальний захід із серверною валідацією, шаблоном
Post/Redirect/Get і збереженням кожного відправлення в окремий UTF-8 файл.

## Структура
- `app.py` — застосунок Flask (маршрути `/form`, `/result`, а також `/`, `/info`, `/hello/<name>` з лаб. №4)
- `templates/form.html` — форма з повідомленнями про помилки
- `templates/result.html` — сторінка результатів
- `templates/hello.html.j2` — шаблон з лаб. №4
- `tests/test_form.py` — автоматичні перевірки через `test_client()`
- `simple_server.py` — сервер на `http.server` з лаб. №4
- `instance/submissions/` — створені файли відправлень (виключено з Git)

## Встановлення
```bash
python -m venv venv
source venv/bin/activate        # Windows PowerShell: venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Запуск
```bash
python app.py                   # http://127.0.0.1:5000/form
python tests/test_form.py       # автоматичні перевірки
```

## Поля форми
| Поле | name | Правила |
|---|---|---|
| Ім’я | `name` | обов’язкове, до 80 символів, один рядок |
| Електронна адреса | `email` | обов’язкове, до 254 символів, `[^\s@]+@[^\s@]+\.[^\s@]+` |
| Кількість учасників | `quantity` | обов’язкове, до 3 символів, лише цифри, 1–100 |
| Тема участі | `topic` | обов’язкове, до 200 символів, один рядок |

## Відповіді
| Ситуація | Код |
|---|---|
| GET `/form` | 200 |
| POST, помилки валідації (файл не створюється) | 422 |
| POST успішний (перенаправлення на `/result`) | 303 |
| POST, збій запису файлу | 500 |
| Тіло запиту більше 16 КБ | 413 |
